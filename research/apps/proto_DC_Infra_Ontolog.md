> 작성 규칙: 본 계획서에서는 **임시 형태의 시제품**으로만 언급하고, 평가 범위(3.5~3.6)와 4.1 사례 표에는 넣지 않는다.

- 저장소: https://github.com/sangchuls/DC_Infra_Ontolog (public, 6커밋 2026-09-12~10-22, Python 약 2,400줄)
- 구성 ✔: Python 계산 엔진(`engine/`: 구조·발전기 급배기·냉동기, 다른 앱 로직을 이식) + LLM 에이전트(`agent/`: Claude/Gemini/GPT 선택, 도구 호출로 계산 후 검토의견서 생성) + 프로젝트별 온톨로지 JSON 지식베이스(`data/knowledge_base/`) + 웹 UI(BYOK: 사용자 API 키 입력)

- 계획서 연결: 2.6(AI·온톨로지 연구와의 경계), 1.4/5.4(온톨로지·BIM 연계는 후속 연구)에서 "본 연구 범위 밖의 시제품, 후속 연구의 출발점"으로 한 문장만 언급. 앱 이식(다른 앱 계산을 Python 도구로 래핑)은 후속 연구의 "API 기반 계산 연동" 근거로 인용 가능
