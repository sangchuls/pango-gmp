## 3. 피드백 기능 (3.4·RQ4에 앱 ①보다 풍부한 선행 사례) ✔
- 📝 버튼: 의견·버그 입력 → 목록 누적 → 관리자가 `반영 / 보류 / 반려` 분류 (README, script.js 번역 키)
- `server.js` 실행 시 모든 사용자 피드백이 `feedback.json`에 수집(서버 연동), 서버 없으면 그 브라우저에만 저장하고 JSON 내보내기로 전달 ✔
- 첨부된 설계값을 `설계값 불러오기`로 재현 가능 → 재현 조건 수집(4.3 피드백 입력 양식의 "재현 조건"에 해당)
- 관리자 인증: `FEEDBACK_ADMIN_KEY` 설정 시에만 조회·변경·삭제 제한. **키 미설정 시 `fbIsAdmin`이 모두 허용** (server.js:128) → 공개 배포 시 설정 누락 위험 ✔
- 앱 ①은 `mailto` 방식이라 접수 이력이 개발자 측에 남지 않음 → 3.4의 구현 선택지 비교(mailto vs 서버 수집)를 두 앱 사례로 설명 가능
