## 1. 목적·기능 ✔
- 발전기 제조사 카탈로그(Cummins, Caterpillar, MTU, Rehlko, 직접 입력) 기반 발전기실 급기(OA)·배기(EA) 유효 개구면적 산출. 부재별(DA, 소음기, 댐퍼, 그릴) gross/net 면적, 허용풍속 검토, CAD 실측 면적 비교표, 산식 메모
- React(Babel 인라인), Vercel 정적+서버리스

## 2. 구조의 특징 (연구와의 연결점) ✔
- **계산 로직 단일 원본**: `lib/calc.js`를 브라우저 UI와 서버리스 API(`GET/POST /api/compute`)가 공유. 카탈로그·공식 수정이 화면과 API에 동시 반영 (파일 상단 주석)
- 카탈로그가 **데이터**로 분리: 제조사×kW별 `qcool, qcomb, cat_oa, cat_ea`, 출처 주석 "GnCenergy 카탈로그 p.13/14/18"
- 확정 기준값 출처 명시: "GnC에너지 공문 2026-05 + Cummins C3000D6EB 사양서" (`DEF`)
- → 3.3의 "MD→앱 지식 원본", 1.4/5.4의 "API 기반 계산 연동"(후속 연구)의 가장 구체적인 선행 구현. 앱 ①·②·③에는 API가 없음. DC_Infra_Ontolog 시제품이 이 로직을 Python으로 이식함(같은 결과 69.12/54.72 확인)

## 3. 계산식과 검증 (이번에 확인)
| 산식 | 코드 | 확인 |
|---|---|---|
| gross(1대) = Q_unit × 여유율 ÷ (설계풍속 × 개구율η) | `compute` | 수기 계산 일치: Cummins 3,000kW 급기 DA = 7.2×7.0×1.2÷(7.0×1.0) = 8.64㎡ ✔ |
| 급기 면적 환산 = (연소풍량+냉각풍량)÷60÷V | `oa_q` | (262+2751)÷60÷7 = 7.17㎡ ✔ |
| 배기 면적 환산 = 냉각풍량÷60÷V | `ea_q` | 2751÷60÷8 = 5.73㎡ ✔ |
| 합계 OA = oa × n × 여유율 | `OA` | 7.2×8×1.2 = 69.12㎡, EA 5.7×8×1.2 = 54.72㎡ ✔ |
- **내장된 교차 점검**: 카탈로그 개구면적(7.2, 5.7)과 풍량에서 역산한 값(7.17, 5.73)을 함께 출력 → 지식 입력값의 자체 일관성 점검 사례
- `node`로 `computeFromParams`를 직접 실행해 위 값 재현 ✔
- 한계: 테스트 파일 없음(`test|spec` 0건) ✔. 카탈로그 수치(PDF)와 코드 입력값의 전수 대조는 하지 않음 [확인 필요]. 이것은 산식·입력 일치이며 설계 적정성 검증이 아님
