■ 제목

DC Review Micro-Apps — 설계자가 직접 만든 데이터센터 초기 설계 검토 앱


■ 본문

[Summary]
협력업체 계약 전 데이터센터 초기 설계에서 설계 실무자가 규모(평면·단면)를 검토할 수 있도록, 전력 이중화·데이터홀 단면·발전기실 급·배기 검토 앱을 Claude Code로 직접 개발했습니다.

① 배경 및 목적
· 데이터센터는 전기실·발전기실·데이터홀 규모가 건물 전체를 좌우하지만, 초기에는 업체 계약 전이라 추정하거나 회신을 기다려야 했습니다.
· 협의하며 쌓은 검토 지식을 도구로 만들어, 업체 검토 전에도 근거 있는 수치를 확인하는 것이 목표입니다.

② 활용 방법
· Claude Code(바이브 코딩)로 개발 → GitHub 저장 → Vercel로 웹 배포
· 앱 A 전력 이중화: 전기실 구성 / 앱 B 데이터홀 단면: 층고·규모 / 앱 C 발전기실 급·배기: 그릴 면적

③ 결과
· 조건을 입력하면 산식과 도면으로 즉시 결과 확인, 초과·간섭은 자동 경고
· 데이터센터 프로젝트에 시범 적용 중 (팀원 사용, 협력업체 의견 반영)

④ 인사이트
· 핵심은 코딩 실력이 아니라 업무 지식입니다.
· AI가 만든 계산은 반드시 따로 검증해야 합니다. 결과는 개략 검토용입니다.
· 다음 목표: 앱을 연결해 AI가 종합 검토의견서를 만드는 시스템
