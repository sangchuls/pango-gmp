# 원본 초안(v1) 대비 반영표

v1 = 저자 원본(온톨로지·AI 에이전트 중심), v2 = 범위 축소 수정본(다른 도구로 작성), v5 = 이번 제출본.
v5는 처음 정한 규칙(온톨로지는 임시 시제품으로만 언급, 평가 범위 제외)에 따라 v2의 범위를 유지하고, v1에서 이와 충돌하지 않는 내용을 되살렸다.

## v1에서 되살린 내용
| v1 위치 | v5 위치 | 내용 |
|---|---|---|

| 2.2, 참고문헌 | 2.2 | 박종진 외(2022) 추가, 엄미영·이용주 원본 서술은 원문 확인 항목으로 보존 |

## 범위가 달라 반영하지 않은 내용 (저자 판단 필요)
| 항목 | v1 | v5 |

| 연구 목적 | 온톨로지 기반 AI 의사결정 지원 프레임워크 | MD·앱·통합 공유·피드백 개선 프레임워크 |
| 비교 조건 | 수작업 / LLM+Micro-App / +온톨로지 | 수작업 / 개별 앱 / 통합 플랫폼 |
